# Azure AI Architecture Research Prompt

## Objective

Generate a technical research report explaining the architecture and ecosystem of Azure AI services used to build modern AI applications.

---

## Requirements

Produce a detailed technical document of **4000–6000 words** explaining how Azure AI services integrate into enterprise AI architectures.

The report should include:

1. Executive Summary
2. Overview of Azure AI ecosystem
3. Azure OpenAI
4. Azure AI Search
5. Azure Machine Learning
6. Azure AI Foundry
7. Vector Search in Azure
8. Retrieval-Augmented Generation in Azure
9. Building AI Applications on Azure
10. Security and Identity
11. Enterprise Architecture Patterns
12. Monitoring and Governance
13. Real-world Use Cases
14. Future of Azure AI
15. Conclusion
16. References

---

## Topics to Cover

Include discussion of:

- Azure OpenAI
- Azure AI Search
- Azure Machine Learning
- Azure AI Foundry
- Vector search
- RAG systems
- AI agents on Azure
- Enterprise AI architectures

---

## Style

The report should:

- resemble a cloud architecture whitepaper
- include references to official Microsoft documentation
- include diagrams and architecture explanations
- be written in a professional tone

---

## Output Format

Generate the document suitable for export to:

- PDF
- Markdown
- Word
