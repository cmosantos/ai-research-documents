# RAG Architecture Research Prompt

## Objective

Generate a comprehensive technical research report explaining the architecture of Retrieval-Augmented Generation (RAG) systems.

The document should explain both the theoretical foundations and practical implementations used in modern enterprise AI systems.

---

## Requirements

Produce a structured technical report of **4000–6000 words** including numbered sections and citations.

The report should contain the following sections:

1. Executive Summary
2. Introduction to Retrieval-Augmented Generation
3. Parametric vs Non-Parametric Memory
4. Core RAG Architecture
5. Document Ingestion Pipelines
6. Chunking Strategies
7. Embeddings and Vector Representations
8. Vector Databases
9. Retrieval Techniques
10. Hybrid Search (Dense + Sparse Retrieval)
11. Reranking and Semantic Ranking
12. Prompt Construction
13. Generation Phase
14. Monitoring and Evaluation
15. Enterprise Use Cases
16. Security Considerations
17. Future of Retrieval-Augmented AI
18. Conclusion
19. References

---

## Technologies to Reference

Include discussion of:

- Vector databases
- Embeddings
- Semantic search
- Azure AI Search
- Pinecone
- FAISS
- Hybrid retrieval
- RRF ranking
- HNSW indexing

---

## Style

The report should:

- resemble a professional architecture whitepaper
- include references and citations
- include diagrams when possible
- include links to research papers

---

## Output Format

Generate a document suitable for export to:

- PDF
- Markdown
- Word
