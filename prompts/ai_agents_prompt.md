# AI Agents Research Prompt

## Objective

Generate a deep technical research report about AI Agents and Autonomous Workflows.

The report should resemble an academic or industry whitepaper and explain the architecture, principles, and real-world applications of modern AI agent systems.

---

## Requirements

Produce a detailed report of approximately **4000–6000 words** with structured sections and numbered headings.

The document should include:

1. Executive Summary
2. Introduction to AI Agents
3. Historical Background of Intelligent Agents
4. Core Components of AI Agents
   - Perception
   - Reasoning
   - Planning
   - Memory
   - Action
5. Architectures for AI Agents
6. Multi-Agent Systems
7. Tool-Using Agents
8. Frameworks and Ecosystem
9. Enterprise Applications
10. Risks, Security and Governance
11. Future of Autonomous Systems
12. Conclusion
13. References

---

## Topics to Cover

The report must explain and reference:

- LangChain
- CrewAI
- AutoGen
- Microsoft Agent Framework
- LangGraph
- ReAct architecture
- Toolformer
- MRKL systems
- Multi-agent orchestration

---

## Style

The report should:

- be written in an academic / professional tone
- include citations and references
- reference research papers when possible
- provide links to documentation or repositories
- include structured headings
- resemble a professional research document

---

## Output Format

Generate the document as a structured report suitable for export to:

- PDF
- Markdown
- Word
